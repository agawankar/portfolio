# Abhijit Gawankar — React + Material UI Portfolio

Static personal portfolio built with React.js, Vite and Material UI. No backend is required.

## Run
npm install
npm run dev

Open http://localhost:5173

## Build
npm run build
npm run preview

## Resume
The latest resume is included under `public/Abhijit_Prakash_Gawankar_Resume.docx` and is linked from the hero section.

## Deploy
This is a static Vite app and can be deployed to GitHub Pages, Netlify, Vercel or any static host.

## Customize
Most portfolio content is in `src/App.jsx`; visual styling is in `src/styles.css`.
